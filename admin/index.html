Écrire un billet

Cette page publie directement dans le dépôt GitHub du site. Pour t'identifier, colle ici ton token GitHub : il reste dans ton navigateur et n'est envoyé qu'à GitHub.

Comment créer le token ?
  1. Sur GitHub : Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access : « Only select repositories », puis bureau-des-projets.
  3. Permissions → Repository permissions → Contents : « Read and write ».
  4. Choisis une durée d'expiration, génère, copie le token et colle-le ci-dessus.

Ne mets jamais ce token dans un fichier du site. Si tu le perds ou le soupçonnes d'être exposé, révoque-le sur GitHub et crées-en un autre.
